Suspended Hosting — Review

Accounts the nightly job found with lapsed billing

This switches off a live customer website. The nightly job only detects — nothing is suspended automatically, because the match between a lapsed billing contract and a hosting account is made by name and is not always reliable. Check the domain, then suspend.

The billing system says these are lapsed, but no account on our panels could be matched to them — usually because the customer record holds a person's name rather than a domain. Chase these with billing; they are never suspended automatically.

⚡ Command Line Automation & API

You can also provision accounts directly from terminal or integrate into external systems:

CLI Terminal Provisioning
# Provision on cPanel
python3 cli.py create --panel cpanel --domain customer.bt --email client@bt.bt --save

# Provision on DirectAdmin
python3 cli.py create --panel directadmin --domain client2.bt --email client@bt.bt

# Test Server Connections
python3 cli.py test --panel cpanel
python3 cli.py test --panel directadmin
REST API Webhook Endpoint
# POST /api/v1/accounts/create
curl -X POST http://localhost:8000/api/v1/accounts/create \
  -H "Content-Type: application/json" \
  -d '{
    "panel": "cpanel",
    "domain": "customer.bt",
    "email": "client@bt.bt"
  }'
